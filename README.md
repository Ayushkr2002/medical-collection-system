# Medical Sample Collection System

A full-stack MERN application for booking medical tests with home sample collection.

## Features

- User Authentication (JWT)
- Book Medical Tests
- Admin Dashboard
- Manage Tests
- Manage Bookings
- Upload Reports
- Responsive UI
- Modern Animations using Framer Motion

## Tech Stack

Frontend
- React
- Vite
- Tailwind CSS
- Axios
- Framer Motion

Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
